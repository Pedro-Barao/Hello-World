## Como o repositório está organizado
Cada linguagem ou matéria tem uma pasta, e dentro dela cada conteúdo (assunto) tem a mesma forma:

```
Linguagem ou Matéria/
├── Conteúdo/                      um assunto (por exemplo "Ponteiro" ou "Funções")
│   ├── Exercícios/
│   │   ├── Enunciados/            só existe se houver enunciado
│   │   └── Respostas/
│   └── Documentos/                arquivos da matéria: aulas e slides (PDF só local), exemplos de código
└── Trilha/                        só onde há trilha guiada (hoje, Oracle SQL)
```
